# Contributing

Bug reports, improvements, and noncommercial forks are welcome. Thank you for making this small utility better.

For bugs, describe your macOS version, what you expected, and what happened. Use synthetic PGN samples and remove personal information from logs and screenshots. For substantial changes, open an issue first so we can discuss the scope.

Run `./app/scripts/test.sh` and `./app/scripts/build.sh` from the repository root before submitting a pull request. See [TESTING.md](TESTING.md) for manual checks. Keep UI and documentation in English.

By submitting a contribution, you agree to license it under the project's [PolyForm Noncommercial License 1.0.0](LICENSE). Only contribute work you have the right to share. Preserve required notices in forks and distributions.
